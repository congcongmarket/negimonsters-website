# NEGI MONSTERS static website

This export uses plain HTML, CSS, and JavaScript. It has no build step or framework dependency.

## Preview

Open `index.html` directly in a browser, or serve the folder with any static web server.

## Files

- `index.html` — page structure
- `styles.css` — desktop/mobile layout and visual styles
- `script.js` — multilingual content, language switching, character details, and order panel interactions
- `assets/` — images exported from the Figma-based website

## Common edits

- Replace character text or multilingual copy in `script.js`.
- Replace product images in `assets/` while keeping the same filenames, or update their paths in `script.js`.
- Update Instagram and email links in `index.html`.
